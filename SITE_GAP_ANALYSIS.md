Every official university and government host is refused by this environment's network policy (latest checks 10:07–14:37 UTC on 2026-10-12, all 403 to CONNECT). **Exact action:** in the session title bar, open the cloud environment menu → Edit → Network access → Allowed domains, add the 20 hosts in `OWNER_ACTION_SHEET.md` §1 (keep "Allow package managers" ticked) and send "hosts added". A broader access level would also work, but it opens far more than this work needs. **Alternative:** send saved copies (PDF with address and date) of the pages listed in `research/verification/CAPTURE_REQUEST_2026-10-12.md` §2, then `CAPTURE_REQUEST_WAVE2_2026-10-12.md`. The workflow was then stopped to save time: each remaining finding was reproduced in the code before it was fixed, and the consistency and documents area was covered by a targeted sweep for stale counts.
