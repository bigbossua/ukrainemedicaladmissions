Security

Your browser sends our forms over an encrypted connection (HTTPS). Form submissions are stored outside the public web directories, in files that only our hosting account can read. Access to that account and to our business mailbox is limited to the people who need it. We do not accept documents through this website; please do not email us documents either.

What else is stored with a submission

With each enquiry or candidate profile we store a reference number, the date and time we received it, a note that you ticked the consent box with a short description of what you agreed to and, where our abuse protection is switched on, a pseudonymised code made from your IP address. The code is a keyed hash that changes every month; your IP address itself is not stored with your submission. We use the code only to detect abuse, for example to refuse repeated submissions from the same connection within an hour; for this, the code and the times of recent submissions are also kept in a separate file, which is deleted once it is more than an hour old, at the next submission. If the email copy of your submission could not be sent, we note that too.
